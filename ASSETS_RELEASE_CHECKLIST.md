## Before publishing
1. Review and approve all original photos, diagrams and videos for public use, including worker consent and customer/project logos.
2. Generate compressed and corrected WebP files from approved images only.
3. For videos, verify MP4 codecs, duration, resolution, audio, poster, and right to distribute. Add real first-party media, then test mobile playback.
4. Verify CV contact information and project/job dates.
5. Test both languages, keyboard controls and layouts on mobile and desktop.
6. Remove the noindex/robots restriction only after approval.
7. Connect only the dedicated Vercel project to `andrew.atstudioimpact.com`. Do not attach to ATS site project.
8. Generate the CV QR code only when this permanent domain is active.
